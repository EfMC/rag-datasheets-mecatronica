Asistente RAG que responde preguntas técnicas sobre datasheets y manuales de mecatrónica
(microcontroladores, PLC, transistores, sensores, servomotores, amplificadores) citando
el documento y la página de cada dato.

Cada persona usa su propia clave gratuita de la API de Gemini
([aistudio.google.com/apikey](https://aistudio.google.com/apikey)). La clave se usa solo
para sus preguntas y no se guarda en el servidor.

Código: [EfMC/rag-datasheets-mecatronica](https://github.com/EfMC/rag-datasheets-mecatronica)
